# Skill Manager 工作台设计 · v0.4

对象是同时使用多个客户端、管理几十项 Skill 的开发者。首页的任务是快速识别资源、筛选并切换启用状态，保留足够的上下文来安全恢复。

## 设计方向

采用紧凑的资源工作台：稳定的深色项目导航、较轻的画布、独立资源面板。主题只改变视觉偏好，成功、警告与冲突始终保留不同的语义色及文字／图标。

比较过将主题放进设置页和直接铺满首页两种方式；最终使用页头常驻入口展开四张完整工作台预览。它占用一个操作按钮的空间，选择后仍保留预览，方便连续比较，点击空白或 Esc 收起。

```text
项目导航 │ 工作空间 / 项目             [主题 ▾] [刷新]
         │ 项目名 / 分支               [提交前恢复]
         │ 提交保护与当前状态
         │ 类型 / 搜索 / 分组 / 重置筛选
         │ 已选数量 + 筛选外数量 + 批量操作
         │ 资源名称与描述        来源    状态    开关
```

全局使用同一套结构，将列表右侧换成客户端矩阵，并把分组、仓库和备份放到主页面快捷入口。独特元素是主题卡片中的微型工作台：导航、画布、面板、文本条和状态灯对应真实配色，便于判断整体工作环境。

## 交互修正

- 首页主题即时切换，localStorage 记住选择；非法偏好值回退信号蓝。
- Cmd/Ctrl + K 聚焦当前可见搜索框，支持清空与重置全部筛选。
- 全选框呈现半选状态，跨筛选选择显示隐藏项数量，避免批量操作范围不明。
- 全局列表旁增加批量操作栏和取消选择，管理弹窗内可搜索 Skill。
- 全局页面切换到项目页后保留查询、选中项和当前流程。
- 共享弹窗组件只处理最上层 Esc，Tab 跳过禁用及不可见控件，并恢复打开前的焦点；长弹窗标题和确认操作保持可达。
- 项目场景／分组名称支持 Enter 保存。
- 增强状态对比度、表格选中反馈、客户端开关尺寸及代码正文可读性。
