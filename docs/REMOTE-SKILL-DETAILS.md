# 搜索结果详情 · v0.4.1

搜索结果的 Skill 名称与“查看详情”均可点击。详情先下载仓库到本应用缓存，只读取完整 SKILL.md、简介、来源仓库、分支、精确路径和文件清单。它不会创建安装计划，不会写入技能库，也不会创建客户端链接；本机存在同名 Skill 不妨碍查看。

搜索结果的标识与仓库候选路径／名称唯一匹配时直接打开。找不到唯一匹配时，选择器列出候选路径供用户确认。直接读取仓库得到的每项 Skill 同样支持详情入口。

在详情底部点击“预览安装”，再核对现有安装预览并确认，才会安装。关闭安装预览返回详情；关闭详情保留原搜索结果。网络和读取错误在详情内显示，并支持重新读取。

正文以只读 Markdown 源文显示，保留所有文字。超过 2 MB 或无效 UTF-8 时显示明确错误，不静默截断；文件清单支持展开与滚动。远端内容不执行 HTML 或脚本。
