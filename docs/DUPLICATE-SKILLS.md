# 全局重复 Skill 管理

入口：全局 Skill → 重复检查（入口数字为同名多来源组数）。

1. 扫描自动合并指向同一实际目录的软链接；重复检查针对不同实际目录中的同名 Skill。
2. 比较完整目录结构、每个文件的 SHA-256、内部相对软链接目标以及 Unix 权限，不只比较 SKILL.md。无法安全读取的目录单独提示。
3. 每组默认选当前共享库中的来源作为保留源；可切换保留源、查看每份 SKILL.md、搜索路径，以及批量选择当前可合并的组。切换保留源后需要重新勾选该组。
4. 默认只将与保留源完全相同的副本纳入预览；可展开差异查看具体文件及权限值。要统一不同版本，改选“仅保留所选版本”，再选择保留源并勾选该组。其他版本将备份移出，原入口改用保留源；更新来源以保留版本为准。选择保留源不等于同意执行文件变更。
5. 预览列出保留路径、副本路径、备份位置和完整文件移动清单。确认后，将每份副本完整移动至应用数据目录的 `global/admin-plans/<token>/duplicate-backup-*`，在原位置建立指向保留源的软链接。已有指向原位置的客户端链接继续可用。
6. 合并后重扫列表，按实际目录归为一项。可在备份中心的“迁移与管理历史”找到“重复 Skill 合并”，预览整批回退。清理下载与预览缓存不会删除已执行操作的备份。

## 数据保护

- 扫描只读；预览只生成应用自己的计划和待部署链接，不移动真实 Skill。
- 执行前重验完整内容、权限、管理状态和路径；外部编辑使旧预览失效。
- 复用管理事务日志、无覆盖移动和反向回滚。每一步失败均可恢复；恢复冲突时保留数据并提示处理。
- 托管记录和客户端启用预期随保留源合并；默认相同副本合并遇到更新来源或基线记录不同、分组不一致时拒绝执行；“仅保留所选版本”则以所选版本的更新信息和分组为准。原版本的受管客户端副本会备份后改为指向所选源的软链接；若客户端有新的本地修改，拒绝执行并给出具体路径。完整旧管理状态保存在可撤销计划中。
- 无法读取、含不安全外部链接或特殊文件的目录，无法验证备份完整性，需先根据具体错误修复再处理。
- 合并后的所有软链接共享同一份内容。不同副本如需继续各自编辑，应保持独立版本。
- 不按名称自动删除，不会自动执行批量整理，也不修改 cc-switch 的数据库。

## 版本 Diff

点击每组“比较版本 Diff”，从同名 Skill 的多个实际来源中任意选择左右两份；支持交换左右。左侧清单默认仅显示差异条目，也可查看相同文件。右侧显示统一格式 Diff：红色减号代表左侧删除行，绿色加号代表右侧新增行，包含双方行号和上下文。

比较覆盖 SKILL.md、references、scripts、evals 等文件，以及文件增删、目录/文件类型变化和权限。软链接对比链接目标文本，不跟随链接读取其他文件。单个文本文件上限 1 MB、12,000 行，超过限制、二进制或非 UTF-8 文件明确提示，不截断后伪装成完整 Diff。换行格式单独显示，末尾缺少换行在 Diff 中标记。

比较本身只读；系统 Diff 只接触临时文本副本，不在源仓库执行命令。来源选择器下方直接提供“保留左侧，右侧改为软链接”和反向按钮，点击后进入备份与软链接预览，勾选确认后点击“确认应用并建立软链接”。无需返回列表选择模式或再次勾选。仅处理当前左右两份；三份及以上来源的其他版本不参与本次操作。取消预览返回原 Diff，保留左右来源和当前文件；完成后自动刷新并关闭旧比较。选择来源、文件或关闭弹窗时，过期读取结果不会覆盖当前比较。
